# vitamin-vending

책상 위 영양제 자판기. 통 10개에 먹던 영양제를 그대로 붓고, 버튼 한 번이면 오늘 먹을 만큼이 컵 하나에 모여 나온다.

A tiny supplement vending machine I'm building for myself.

이름은 아직 없다. 인스타그램에서 공모 예정.

## 왜 만드나

영양제 챙겨 먹기가 귀찮아서. 사서 쓰려고 찾아봤는데 마땅한 게 없어서 직접 만든다.

## 어떻게 동작하나

```
┌───────────────────────────────┐
│ [1]  [2]  [3]  [4]  [5]       │  투명 캐니스터 (남은 양 보임)
│ [6]  [7]  [8]  [9]  [10]      │
├───────────────────────────────┤
│     ● 오늘 먹기     [OLED]     │  물리 버튼 + 앱
├───────────────────────────────┤
│          ┌───────┐            │
│          │  컵   │            │  한 곳으로 모여 나옴
│          └───────┘            │
└───────────────────────────────┘
```

1. 캐니스터마다 알약 크기에 맞춘 3D 프린트 로터가 들어간다. 로터가 돌면 슬롯에 한 알씩 걸려 떨어진다.
2. IR 센서가 실제로 떨어진 알약을 센다. 설정한 개수가 될 때까지만 돌린다.
3. 각 캐니스터에서 떨어진 알약이 깔때기를 타고 컵 하나로 모인다.

## 앱 (Bluetooth LE)

- 칸 번호별 영양제 등록, 1회 개수 설정
- 앱에서 누르면 기계에서 배출
- 매일 복용 기록, 복용 알림
- 남은 개수 추적 → 떨어지기 전 재구매 알림

설정은 기계에 저장된다. 폰이 없어도 물리 버튼으로 나온다.

## 하드웨어

| 부품 | 수량 |
|---|---|
| ESP32-S3 | 1 |
| 28BYJ-48 스테퍼 + ULN2003 | 칸당 1 |
| 74HC595 (데이지 체인) | 5 |
| IR 브레이크빔 센서 | 칸당 1 |
| 0.96" OLED (SSD1306) | 1 |
| 버튼, 5V 3A 전원 | 1 |
| PETG 3D 프린트 부품 | 본체, 로터, 캐니스터 |

10칸 기준 부품비 약 15만 원. 안 쓰는 칸은 모터·센서를 빼면 더 싸다.
